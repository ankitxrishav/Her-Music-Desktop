## ✨ Key Features

- **💑 Connect & Listen Together**: Host or join a room with a 6-letter room code. Song playback, queue changes, and seeks sync in real-time between macOS, Windows, and the Her Music Android mobile app.
- **🎧 Lossless High-Fidelity Audio**: Powered by libmpv with bit-perfect audio output, gapless playback, and high-performance caching.
- **🎤 Real-Time Synced Lyrics**: Word-by-word synced karaoke lyrics with live syllable animation, powered by multi-provider fallbacks (Paxsenix, LRCLIB, BetterLyrics, Kugou, SimpMusic).
- **📱 YouTube Music & Lossless Discovery**: Stream millions of tracks, browse top charts, explore moods & genres, and generate smart playlists.
- **🔗 Smart Playlist Import**: Import your favorite playlists directly from YouTube, Spotify, and Apple Music.
- **🎨 Atmospheric Velvet UI**: Elegant obsidian & soft rose/magenta aesthetic with native macOS translucent materials, Windows Mica styling, and mini player.
- **💬 Couple Reactions & Chat**: Send love vibes and live messages while listening together.
- **🎮 Discord Rich Presence**: Show what you are listening to on Discord with interactive buttons.

## 🛠️ Building from Source

```bash
# Clone the repository
git clone https://github.com/ankitxrishav/Her-Music-Desktop.git
cd Her-Music-Desktop

# Install dependencies
flutter pub get

# Run on macOS
flutter run -d macos

# Run on Windows
flutter run -d windows
```
